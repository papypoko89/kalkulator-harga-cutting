# Kalkulator Harga Jasa Cutting

Aplikasi web sederhana untuk menghitung harga jasa cutting berdasarkan master harga lokal.

## Fitur

- Kalkulator harga berdasarkan bahan, density, ketebalan, ukuran, dan qty.
- Master data harga tersimpan di `localStorage`.
- Tambah, edit, hapus, aktif/nonaktif data harga.
- Export dan import master data JSON.
- Copy estimasi ke format WhatsApp.

## Menjalankan Lokal

```powershell
npm install
npm run dev
```

Buka `http://127.0.0.1:3000`.
